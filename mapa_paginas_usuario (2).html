Mapa de páginas do sistema de comunicados — visão do aluno

Páginas por papel: Aluno Grêmio Admin
Feed de comunicados
/feed
Página inicial do aluno após login. Lista todos os comunicados ativos direcionados ao seu perfil (curso + sala + turno).
Componentes
Filtros e ordenação
  • Filtro por prioridade (todas / urgente / alta / média / baixa)
  • Filtro por tipo (obrigatório / opcional)
  • Ordenação padrão por prioridade desc, depois por data
  • Toggle "somente não lidos"
Card de comunicado
  • Título + trecho do texto (truncado)
  • Badge de prioridade colorido
  • Badge "obrigatório" em destaque
  • Data de início e fim
  • Autor (nome + papel)
  • Indicador visual de não lido (bolinha)
  • Miniatura da imagem (se houver)
  • Público-alvo resumido (ex: "Turma A – Manhã")
Header da página
  • Badge com contagem de não lidos
  • Saudação com nome do aluno
  • Atalho para agenda pessoal
Detalhe do comunicado
/comunicados/:id
Exibe o comunicado completo. É o ponto central de interação do aluno com o evento.
Componentes
Conteúdo principal
  • Título grande
  • Imagem em destaque (se houver)
  • Texto completo renderizado
  • Autor + data de publicação
  • Período de vigência (início → fim)
  • Público-alvo detalhado
  • Badge de prioridade
Ação de presença
  • Botão "Confirmar presença" (opt-in para opcionais)
  • Status atual (confirmado / desmarcado / automático)
  • Se obrigatório: aviso "Presença automática registrada"
  • Botão "Desmarcar" abre modal com campo de justificativa
  • Validação: mínimo de N caracteres na justificativa
  • Contador de confirmações visíveis ao aluno
Agenda
  • Indicador "na sua agenda" (se confirmado)
  • Link rápido "Ver na agenda"
Agenda pessoal
/agenda
Calendário individual do aluno com todos os eventos confirmados (manuais e automáticos).
Componentes
Calendário mensal
  • Visualização por mês com navegação anterior / próximo
  • Dias com evento marcados visualmente
  • Cor diferente para obrigatórios vs confirmados pelo aluno
  • Clique no dia expande lista de eventos do dia
Lista lateral / expandida
  • Card resumido de cada evento do dia selecionado
  • Status de presença com ícone
  • Justificativa exibida (se desmarcado)
  • Atalho para detalhe do comunicado
  • Botão de desmarcar presença direto da agenda
Filtros
  • Exibir somente obrigatórios
  • Exibir somente confirmados pelo aluno
  • Exibir eventos passados (ocultos por padrão)
Meus comunicados
/meus-comunicados
Painel principal do grêmio. Lista todos os comunicados criados com status e ações disponíveis.
Componentes
Tabela de comunicados
  • Colunas: título, prioridade, período, status, presenças
  • Status visual: rascunho / aguardando / publicado / rejeitado
  • Motivo de rejeição acessível via tooltip ou expandindo linha
  • Ações por linha: editar, ver presenças, arquivar
Ação principal
  • Botão "Novo comunicado" — vai para editor
  • Aviso visível se permissão do grêmio estiver desativada pela adm
Filtros
  • Por status
  • Por período
  • Busca por título
Editor de comunicado
/comunicados/novo  ·  /comunicados/:id/editar
Formulário de criação e edição de comunicados. Mesma página para novo e edição.
Componentes
Campos do formulário
  • Título (input texto)
  • Texto (editor rich text ou markdown)
  • Upload de imagem opcional com preview
  • Prioridade (select: baixa / média / alta / urgente)
  • Data de início e fim (date-time pickers)
Seletor de público-alvo
  • Opção "Escola inteira" (desativa os demais)
  • Multi-select de cursos
  • Multi-select de salas
  • Multi-select de turnos
  • Resumo visual do público selecionado
Ações
  • Salvar rascunho
  • Enviar para aprovação
  • Pré-visualização do comunicado
  • Aviso: "este comunicado será publicado após aprovação da administração"
Painel de presenças
/comunicados/:id/presencas
Visão detalhada de quem confirmou, desmarcou e as justificativas enviadas.
Componentes
Resumo numérico
  • Total do público-alvo
  • Confirmados (count + %)
  • Desmarcados (count + %)
  • Sem ação (count + %)
Lista de alunos
  • Abas: Confirmados / Desmarcados / Sem resposta
  • Nome, sala e turno de cada aluno
  • Data da última ação
  • Justificativa expandível (para desmarcados)
Exportação
  • Exportar lista completa em CSV
  • Exportar somente confirmados
  • Exportar somente desmarcados com justificativas
Painel de aprovação
/admin/aprovacoes
Fila de comunicados do grêmio aguardando revisão. Acesso prioritário — badge de pendências no menu.
Componentes
Fila de pendências
  • Cards ordenados por data de envio (mais antigo primeiro)
  • Preview completo do comunicado inline
  • Público-alvo detalhado
  • Tempo na fila (ex: "há 2 dias")
Ações por comunicado
  • Aprovar (publicação imediata)
  • Rejeitar — abre modal com campo de motivo obrigatório
  • Solicitar ajustes — rejeição com sugestão de edição
  • Ver histórico de revisões anteriores do mesmo rascunho
Todos os comunicados
/admin/comunicados
Visão completa de todos os comunicados do sistema, independente de autor ou status.
Componentes
Tabela completa
  • Colunas: título, autor, prioridade, público, período, status, presenças
  • Ordenação por qualquer coluna
  • Paginação ou scroll infinito
  • Ações: ver detalhe, editar, arquivar, ver presenças
Filtros avançados
  • Por status (múltipla seleção)
  • Por autor / papel do autor
  • Por prioridade
  • Por público-alvo
  • Por período de vigência
  • Busca por título
Página de conflitos
/admin/conflitos
Lista de sobreposições detectadas automaticamente. Cada conflito exige resolução antes de ser arquivado.
Componentes
Card de conflito
  • Os dois comunicados lado a lado
  • Sobreposição destacada: período e público em conflito
  • Quem criou cada um e quando
  • Status de resolução
Ações de resolução
  • Descartar comunicado A ou B
  • Editar data de um dos dois (redireciona para editor)
  • Editar público de um dos dois
  • Marcar como resolvido manualmente
Histórico
  • Conflitos resolvidos arquivados
  • Tipo de resolução aplicada
  • Quem resolveu e quando
Gestão de usuários
/admin/usuarios
CRUD completo de usuários com atribuição de papéis e dados de perfil escolar.
Componentes
Tabela de usuários
  • Nome, email, papel, curso/sala/turno
  • Status ativo/inativo
  • Data de criação
  • Ações: editar, desativar, resetar senha
Formulário de usuário
  • Nome e email
  • Papel (admin / grêmio / aluno)
  • Curso, sala e turno (para alunos)
  • Ativar/desativar conta
Configurações do sistema
/admin/configuracoes
Parâmetros globais que afetam o comportamento do sistema.
Componentes
Toggles
  • Habilitar / desabilitar publicações do grêmio
  • Exigir aprovação para o grêmio (sempre ativo quando grêmio habilitado)
Parâmetros
  • Mínimo de caracteres para justificativa de desmarcação
  • E-mail remetente das notificações
  • Prazo máximo para resolver conflitos (dias)
Login
/login
Entrada única para todos os papéis. Redireciona automaticamente para a página inicial do papel após autenticação.
Componentes
Formulário
  • Campo email
  • Campo senha com toggle de visibilidade
  • Botão entrar
  • Link "esqueci minha senha"
  • Mensagem de erro clara em caso de falha
Meu perfil
/perfil
Dados pessoais do usuário logado. Disponível para todos os papéis.
Componentes
Dados exibidos
  • Nome completo
  • Email
  • Papel no sistema
  • Curso / sala / turno (se aluno)
Ações
  • Alterar senha (campo atual + nova + confirmação)
  • Logout
Página de erro / não autorizado
/403  ·  /404
Exibida quando o usuário acessa uma rota inexistente ou sem permissão.
Componentes
Conteúdo
  • Código do erro (403 / 404)
  • Mensagem amigável explicando o problema
  • Botão "Voltar ao início" para a home do papel
